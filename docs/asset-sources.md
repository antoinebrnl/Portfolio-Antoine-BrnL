# Desktop assets

- `public/wallpapers/pro-black.jpg`: Apple's MacBook Pro **Pro Black** wallpaper, supplied as a visual reference by the project owner. Browser-compatible JPEG from `src/assets/wallpaper.jpg` in [vamsi876/vamsi876.github.io](https://github.com/vamsi876/vamsi876.github.io/blob/1a09e083e56769f4943322f09987b1bfdbadf41a/src/assets/wallpaper.jpg), retained without modification (3456 × 2234). Apple artwork remains attributed to Apple.
- `public/wallpapers/pro-black-terracotta.png`: edited from that Pro Black reference using image generation at the owner's request. Maintains the black curves with subtle terracotta edge reflections; used as the default day/night wallpaper. The original reference is retained above.
- `public/music/mac-startup.mp3`: Mac startup chime from `public/sounds/mac-startup-sound.mp3` in [PuruVJ/macos-web](https://github.com/PuruVJ/macos-web/tree/14204808226d67fce14924d0b2ea889c807f12a9). The source repository's MIT license is preserved alongside the audio as `mac-startup.LICENSE.txt`.

- `src/styles/fonts/Welcome-Caveat.ttf`: Caveat variable font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/caveat), used locally for the welcome handwriting. The SIL Open Font License is preserved as `Welcome-Caveat.LICENSE.txt`.

- `src/styles/fonts/Metropolis-*.woff2`: Metropolis by Chris Simpson, from [dw5/Metropolis](https://github.com/dw5/Metropolis/tree/85fa62524e9eb40047bbf64830022e59a02cbaed/Fonts/Webfonts/WOFF2). Its Unlicense is preserved as `Metropolis.LICENSE.txt`.
- `src/styles/fonts/Orbitron.ttf`: Orbitron variable font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/orbitron), with its SIL Open Font License preserved as `Orbitron.LICENSE.txt`.
- `src/styles/fonts/NotoEmoji.ttf`: monochrome Noto Emoji variable font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notoemoji), used only as a symbol fallback to avoid platform color emoji. Its SIL Open Font License is preserved as `NotoEmoji.LICENSE.txt`.
