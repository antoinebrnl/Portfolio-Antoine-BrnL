# About This Site

This interactive portfolio recreates the macOS Tahoe 26 interface using [React](https://reactjs.org/), [Zustand](https://zustand-demo.pmnd.rs/), [Framer Motion](https://www.framer.com/motion/) and [UnoCSS](https://uno.antfu.me/).

Designed and personalized by [Antoine BrnL](https://antoine-brnl.com). Inspired by the work of [Akash Sharma](https://github.com/aakashsharma003/macOS-Portfolio).
